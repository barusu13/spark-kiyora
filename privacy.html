プライバシーポリシー / Privacy policy

日本語

  • このアプリは個人用で、一般には提供していません。
  • アプリは、利用者が許可した範囲で、利用者自身の Google アカウントのデータにアクセスします。
  • データは利用者自身の機器の中で処理し、保存します。
  • Google のユーザーデータを、販売しません。広告に使いません。利用者の明示的な同意なしに、第三者に提供しません。
  • Google API から受け取った情報の使用は、 Google API サービスのユーザーデータに関するポリシー （限定的な使用の要件を含む）に従います。
  • 利用者は、Google アカウントの設定から、いつでもアクセスの許可を取り消せます。

English

  • This app is for personal use and is not offered to the public.
  • The app accesses the user's own Google account data, within the scopes the user has authorized.
  • Data is processed and stored on the user's own device.
  • Google user data is not sold, not used for advertising, and not shared with third parties without the user's explicit consent.
  • The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • The user can revoke access at any time from the Google Account settings.
