プライバシーポリシー

Spark Kiyora（個人用のアシスタント） · 最終更新 2026-11-10

1. 利用者

このアプリを使うのは、作者本人だけです。ほかの人に提供していません。

2. 扱う Google のデータ

作者本人が許可した、作者自身の Google アカウントのデータを扱います。

  • Gmail：新着メールを読み、重要なメールを本人に知らせるため。本人の指示があるときだけ、送信やラベルの変更をします。
  • Google カレンダー：予定を読み、本人にリマインドするため。本人の指示があるときだけ、予定を作成・削除します。
  • Google ドライブ・ドキュメント・スプレッドシート：本人の指示で、ファイルを探す・読む・作るため。

3. データの保存と処理

データは、作者の自宅にある作者自身のコンピューターの中で処理します。 ログインの情報（トークン）も、そのコンピューターの中にだけ保存します。

4. 第三者への提供

Google のデータを、販売しません。広告に使いません。第三者に提供しません。 本人が自分の作業のために、その都度はっきり承認した場合を除いて、ほかのサービスに送りません。

5. Google API サービスのユーザーデータに関するポリシー

このアプリによる Google API から受け取った情報の使用は、 Google API サービスのユーザーデータに関するポリシー （限定的な使用の要件を含む）に従います。

6. 削除

本人は、Google アカウントの「サードパーティのアプリとサービス」の画面から、いつでもこのアプリの許可を取り消せます。 保存したデータは、本人のコンピューターから削除できます。

Privacy policy (English summary)

Spark Kiyora is used only by its author. It accesses the author's own Gmail, Google Calendar, Drive, Docs and Sheets data, with the author's consent, to notify about important mail, remind of events and manage the author's files. The data and the sign-in tokens are processed and stored on the author's own computer at home. Google user data is not sold, not used for advertising and not shared with third parties; it is sent to another service only when the author explicitly approves it for the author's own task. The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time from the Google Account settings.
